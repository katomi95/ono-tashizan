# おのたしざん

▶ **遊ぶ： https://katomi95.github.io/ono-tashizan/**

ことばに「お」を ひとつ たしてみよう！

「お」の たしざんを まなぶ、ごく ふつうの ちいく きょうざいです。

かね ＋ お ＝ おかね
にぎり ＋ お ＝ おにぎり
なら ＋ お ＝ おなら

ブラウザで動く短編ゲームです。所要時間はだいたい 3〜5 分（「お」を足し続けるかぎり終わりません）。

## 遊び方

| 操作 | 内容 |
| --- | --- |
| 「＋お」ボタン ／ Space ／ Enter ／ O キー | 「お」をたす |
| 点線の枠をクリック | 「お」を入れる場所をえらぶ（後半） |
| 「つぎへ」 | つぎの もんだい |
| 「おわる」 | けっか を みる（さいごの もんだいで「お」を10こ以上たすと出ます） |

音と読み上げ音声が出ます。右上の「おと」「こえ」で切り替えられます。

## 仕様

- ビルド不要。`index.html` を開くか、GitHub Pages にそのまま置けば動きます
- 画像・音声ファイルは一切なし。絵はすべて SVG、BGM（教育番組ふう／雅楽ふう／宇宙ふう）と効果音は Web Audio API でその場生成
- 先生の声はブラウザの音声合成（Web Speech API）。日本語音声がない環境では吹き出しのみ
- フォントのみ Google Fonts（Zen Maru Gothic）を使用

## ファイル

- `js/data.js` … もんだい と せりふ
- `js/items.js` … もんだいの え
- `js/miso.js` … さいごの もんだい（「お」の数に応じて格式が上がる）
- `js/audio.js` … BGM・効果音・読み上げ
- `js/art.js` … キャラクター、かざり、紙吹雪
- `js/game.js` … 進行と状態管理

## 確認用 URL パラメータ

- `?q=8` … 8問目から始める
- `?at=final&n=99` … 最終問題で「お」を99こ足した状態から
- `?at=end&n=127` … 結果画面
